## 1. Цели и задачи тестирования

**Цель** — проверка правильности работы функций вычисления площади и периметра прямоугольника в `rectangle.py`.

**Задачи тестирования:**

- Изучить основные возможности библиотеки `unittest`.
- Разработать тесты для проверки функций `area()` и `perimeter()`.
- Проверить правильность вычислений при разных входных данных.
- Проверить работу программы с нулевыми, целыми, дробными и большими числами.
- Рассмотреть обработку отрицательных значений сторон прямоугольника.
- Сравнить полученные результаты с ожидаемыми.

## 2. Описание тестируемого продукта

Тестируемый продукт — программа `rectangle.py`, написанная на Python.

Программа вычисляет площадь и периметр прямоугольника по заданным длине и ширине.

В программе две функции:

- `area(a, b)` — вычисляет площадь прямоугольника.
- `perimeter(a, b)` — вычисляет периметр прямоугольника.

`a` — длина прямоугольника, `b` — ширина прямоугольника.

Функции принимают числа типа `int` и `float` и возвращают результат вычислений. Для проверки используется библиотека `unittest`.

## 3. Область тестирования

Проверяются функции `area()` и `perimeter()` в следующих случаях:

1. Нулевые значения сторон.
2. Положительные целые числа.
3. Дробные числа.
4. Одна сторона равна нулю.
5. Большие числа.
6. Отрицательные значения сторон прямоугольника.

## 4. Стратегия тестирования

Тестирование выполняется с помощью библиотеки Python `unittest`.

Для тестов создан класс `RectangleTestCase`, который наследуется от `unittest.TestCase`.

Используются следующие методы:

- `assertEqual()` — сравнивает полученный результат с ожидаемым.
- `assertAlmostEqual()` — проверяет приблизительное равенство чисел.
- `assertRaises()` — проверяет возникновение ошибки при некорректных данных.

**Команда для запуска тестов:**

```bash
Python.exe -m unittest rectangle.py
```

## 5. Критерии приемки

Тестирование считается успешным, если:

- Все действующие тесты выполняются без ошибок.
- Функции `area()` и `perimeter()` правильно вычисляют площадь и периметр.
- Программа правильно работает с нулевыми, целыми, дробными и большими числами.
- Полученные результаты совпадают с ожидаемыми.
- Проверки `assertEqual()` и `assertAlmostEqual()` проходят успешно.
- После запуска тестов `unittest` выводит `OK`.

Если тест завершается неудачно, необходимо найти и исправить ошибку.

В программе не предусмотрена проверка отрицательных значений сторон, поэтому проверки с `ValueError` не проходят.

## 6. Ожидаемые результаты

Ожидается успешное выполнение всех 10 действующих тестов.

Функции `area()` и `perimeter()` должны правильно вычислять площадь и периметр прямоугольника для выбранных данных.

После запуска тестов библиотека `unittest` должна вывести `OK`.

Также подготовлены два теста для проверки отрицательных значений сторон.
